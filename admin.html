Опубликовать правки

Для публикации нужен ключ вашего GitHub. Он используется только в этом открытом окне и отправляется только на api.github.com.

Где взять ключ — настройка один раз
  1. Откройте создание ключа GitHub.
  2. Назовите его «Редактор Винсента» и выберите срок действия.
  3. В разделе Repository access выберите Only select repositories и только vincent-books.
  4. В Repository permissions включите Contents → Read and write, затем создайте ключ и скопируйте его сюда.

Ключ не сохраняется в игре, копиях правок или истории публикаций. После закрытия окна он удаляется из памяти редактора.

# Книжная мастерская Винсента — ТЗ

Версия 0.3 · 18 октября 2026 · согласованные решения из чата.

## Задача
Помочь школьникам 1–4 классов запомнить авторов и произведения через понимание содержания. Основа каталога — три фотографии списка, предоставленные пользователем. Винсент, абрикосовый той-пудель в чёрном берете, проводит ребёнка по библиотеке.

## Текущая рабочая версия
- Статический сайт на русском языке; телефон, планшет, компьютер; готовность к GitHub Pages.
- 160 карточек, представляющих все 102 пронумерованные позиции трёх фотографий. Все явно названные произведения включены; циклы и главы «по выбору» представлены отмеченными конкретными текстами. Построчная сверка — CATALOGUE.md.
- Выбор класса, выбор уже пройденных произведений, поиск по названию и автору.
- «Найди пару»: произведение → автор. В раунде до четырёх авторов без повторения. При недостатке авторов раунд короче.
- Вариант мемо: закрытые карточки. Неверная пара остаётся видна до нажатия «Попробовать ещё раз»; таймера нет.
- «Собери полку»: автор → все его произведения среди предложенных. До трёх верных книг, точное количество сообщается. Если в выбранном классе мало разных авторов, отвлекающие книги берутся из общего каталога и не становятся заданиями по содержанию.
- После совпадения — вопрос о каждом произведении. Неверный вариант можно обдумать заново, доступна помощь.
- Результат раунда, личная полка, повторение; звук выключен при первом запуске.

## Карточка произведения
Стабильный ID, название, автор/фольклорная традиция, классы, жанр, краткое содержание, вопрос, варианты и объяснение. У стихов — картина и настроение вместо искусственного сюжета. Описания написаны для игры.

Полные короткие классические тексты и обозначенный школьный отрывок открываются в окне чтения, место в игре сохраняется. В версии 0.3 внутри игры доступны 65 текстов/отрывков общественного достояния, включая выбранные старые русские переводы Андерсена и Перро; у остальных — содержание и ссылка на русский текст. Современные тексты и переводы без разрешения не копируются.

Народная сказка не приписывается собирателю как автору. Циклы «по выбору» и главы не включаются без выбора конкретных текстов. Классы, заданные для целой строки таблицы, переносятся на все произведения этой строки; распределение внутри строки уточняется по учебнику класса.

## Учёт обучения
Для произведения отдельно хранятся самостоятельные ответы об авторе и содержании, использованные направления, помощь, необходимость повторения, дата.

Неверная пара или подсказка не приносит самостоятельную отметку об авторе. Неверный ответ о содержании, чтение карточки или открытие подсказки не приносит самостоятельную отметку о содержании. Результат с помощью всё равно кладёт книгу на полку. Повторять сначала предлагаются книги с ошибками, затем новые. Освоение: минимум два самостоятельных ответа об авторе и два о содержании, участие в обоих режимах и отсутствие последней ошибки. Это условная игровая отметка, не оценка прочтения полного произведения.

Прогресс хранится на устройстве в localStorage; можно выгрузить JSON. Общей таблицы детей и синхронизации между устройствами в первой версии нет. Ссылка на набор передаёт настройки, но не чужой прогресс.

## Визуальный язык
Тёплая бумага, глубокий зелёный, терракотовые акценты, крупные книжные заголовки. Винсент сохраняет признаки референса: абрикосовые кудри, висячие уши, чёрный берет. Иллюстрация — прозрачный PNG, сгенерированный по предоставленному изображению.

Реализовано: мягкое движение Винсента, радость при ответе, задумчивый наклон при ошибке, появление книжек и праздничные бумажные частицы. Уважать системную настройку уменьшения движения. Полноценные покадровые движения лап, моргание и отдельная поза чтения — следующий художественный проход.

Иллюстрации отдельных эпизодов для каждого произведения — следующий художественный проход; сейчас обложки имеют тематические условные изображения. Картинки не должны однозначно выдавать автора.

## Приёмка
1. С телефона 320px все основные действия доступны без горизонтального прокручивания.
2. Каждый раунд можно завершить; неправильный ответ допускает повтор.
3. Несколько книг одного автора не создают неоднозначных пар.
4. Подсказки не считаются самостоятельным знанием.
5. В режиме полки проверяется содержание всех верных книг.
6. Чтение не сбрасывает задание. Есть закрытие Escape и управление с клавиатуры.
7. После обновления сохраняются прогресс, класс и выбранные книги.
8. Прогресс другого ребёнка не передаётся по ссылке.
9. Игра работает в подпапке GitHub Pages без сборки и ключей API.

## Следующие итерации
Уточнение выбора глав и циклов по учебнику Вари; расширение доступного чтения; по 3–5 вопросов на произведение; отдельные художественные сцены и позы Винсента; настоящая лампа и дополнительные украшения на полке; импорт сохранения; тест с Варей и одноклассниками.

## Размещение
Целевой хостинг — GitHub Pages, публичная ссылка для одноклассников. Действующая ссылка: https://marinasalina777-png.github.io/vincent-books/. Файлы публикуются без сборки. Публикация считается завершённой только после получения и проверки URL.


## Награды и аудио · обновление 0.2
Каждые 10 завершённых правильным ответом вопросов по содержанию дают один подарок на выбор. Ответ с подсказкой тоже считается для подарка; учебные самостоятельные отметки при этом продолжают учитываться отдельно. Каждый вопрос приносит не более одного шага после отправки истории на полку. Ошибки счётчик не обнуляют. За очередные 10 ответов выдаётся следующий подарок.

Гардероб: базовый берет, красный шарф, очки с бабочкой, мячик, игрушечная косточка. Два подарочных образа нарисованы отдельно по референсу. Одежда и игрушка выбираются независимо, выбор сохраняется в браузере. У старых сохранений остаётся весь учебный прогресс, новый счётчик подарков начинается с нуля.

Синтетическое озвучивание удалено в версии 0.4. Вместо него в карточках доступны добавленные родителем ссылки на аудиокниги.

Записи прикрепляются HTTPS-ссылкой через редактор и открываются в отдельной вкладке. Для «Лягушки-путешественницы» добавлена отдельная ссылка на актёрское чтение Николая Литвинова на официальном канале ИДДК. Видео и файлы с чужих сайтов не копируются.


## Обновление 0.4 · редактор и самостоятельный ввод

- Голос устройства и все его кнопки удалены. Звук коротких игровых сигналов остаётся необязательным.
- Третий режим «Вспомни названия»: автор → ввод названий по одному → вопросы о содержании → сохранение и подарки. Учитываются написание без кавычек, регистр, «ё/е», небольшие опечатки и явные варианты названия; повторы не засчитываются. Есть подсказка и смена автора.
- «1–4 класс» рядом с 1, 2, 3, 4 снимает индивидуальный выбор и использует весь каталог из 160 книг вперемешку.
- Редактор `admin.html`: поиск по авторам/книгам, классы, обложка с компьютера или по ссылке, описание, ссылка на аудиокнигу, допустимые варианты названия. Черновики в IndexedDB, предпросмотр изолирован от игроков, экспорт/импорт копии.
- Публикация правок из редактора — GitHub Contents API, fine-grained token только с записью Contents в этот репозиторий. Ключ только в памяти, общая версия защищена правами GitHub. Обложки с хешами, проверка конфликтов и SHA, затем обычное развёртывание Pages. Свой сервер не нужен.
- Старый прогресс и гардероб сохраняются. Режим `recall` учитывается как обратное направление наряду с `shelf`.

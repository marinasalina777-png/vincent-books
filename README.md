# Книжная мастерская Винсента

Обучающая игра о литературе для 1–4 классов. Версия 0.5.1: 160 карточек, все 102 пронумерованные позиции присланного списка, два направления сопоставления, мемо, самостоятельный ввод названий, вопросы, чтение и сохранение прогресса. 24 последовательные покупки за учебные монетки, примерочная, интерактивные игрушки и ссылки на аудиокниги. Есть редактор обложек и описаний. Работает без сборки.

## Запуск

Игра и редактор запускаются по HTTP. Для локальной проверки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173. Опубликованные правки загружаются из `overrides.json`. Внешнее подключение используется для шрифтов Google Fonts, картинок по внешним ссылкам и перехода к источникам; при недоступности шрифтов используются системные. Все игровые данные и иллюстрация находятся в репозитории.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `vincent-books`.
2. Загрузите в корень содержимое этой папки, включая `assets` и `.nojekyll`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождитесь успешной публикации и возьмите адрес со страницы Pages.

Относительные пути позволяют разместить игру в `https://<аккаунт>.github.io/<репозиторий>/`.

## Контент и ограничения

Представлены все 95 отечественных и 7 зарубежных пронумерованных позиций фотографий. Они раскрыты в 160 карточек: в строке может быть несколько названий. Открытые циклы, былины, народные жанры и главы «по выбору» представлены конкретными текстами с примечаниями. Все явно перечисленные названия включены. Это покрытие списка, а не утверждение о включении каждого рассказа каждого упомянутого цикла. Полная сверка — `CATALOGUE.md`.

Внутри доступны 65 текстов и обозначенных отрывков общественного достояния. Другие карточки содержат написанные для игры пересказы и ссылки на русские тексты. Современные тексты и переводы без разрешения не копировались. Классы целой строки таблицы перенесены на все её произведения. У совпадающих названий разных авторов на игровом поле показан сюжетный ориентир.

Для каждой книги пока один вопрос. Следующий проход добавит варианты, чтобы ребёнок не запоминал положение или формулировку ответа. Порядок ответов уже перемешивается.

Прогресс хранится в браузере под ключом `vincent-books-v1`. Экспорт доступен в «Об игре». Импорт и синхронизация пока не реализованы. Не добавляйте в публичный репозиторий детские персональные данные, ключи или выгруженные сохранения.


## Редактор карточек

Откройте [admin.html](admin.html). Он доступен также через «Для родителей · редактор» внизу игры.

1. Найдите произведение по названию или автору.
2. Загрузите JPG/PNG/WebP (до 20 МБ; браузер уменьшает до 850 px и JPEG), либо вставьте HTTPS-ссылку на изображение.
3. Измените описание и добавьте HTTPS-ссылку на страницу аудиокниги. Ссылки открываются отдельно; автоматического чтения и воспроизведения нет.
4. Нажмите «Сохранить черновик», затем «Посмотреть в игре». Только URL с `?preview=1` применяет черновики. Обычные игроки видят опубликованную версию.
5. «Опубликовать для всех» отправляет правки в этот же репозиторий GitHub. Дождитесь обновления GitHub Pages.

Для прямой публикации нужен GitHub fine-grained personal access token: только репозиторий `vincent-books`, разрешение **Contents → Read and write**. Пошаговая инструкция есть в окне публикации. Ключ вводится в скрытое поле, отправляется только на `https://api.github.com`, не сохраняется в хранилище, экспорте или репозитории. После закрытия окна или завершения публикации поле очищается. Редактор доступен публично, общую версию может менять лишь владелец подходящего ключа.

Черновики с обложками сохраняются в IndexedDB отдельно от детского прогресса. Кнопки «Скачать копию» / «Восстановить из копии» переносят правки между устройствами. Перед переходом к другой карточке редактор сохраняет заполненную карточку; при закрытии окна с несохранёнными полями браузер предупреждает. Перед публикацией сохраняются все текущие поля.

Обложки публикуются отдельными файлами с хешем в `assets/covers/`; `overrides.json` содержит только пути, описания, ссылки и допустимые варианты названий. Изменения других карточек сохраняются, конфликт правок одной карточки останавливает публикацию. SHA файла защищает от гонки при последней записи. При потере соединения после отправки результат сверяется повторным чтением. Неиспользованные изображения после неудачной публикации не влияют на каталог.

Встроенное синтетическое озвучивание удалено. `narration.js` оставлен пустой совместимой заглушкой, не подключается к игре. Звуковые эффекты описаны в разделе «Звуки · 0.5.2».

## Самостоятельный ввод

«Вспомни названия»: случайно выбирается автор из текущего набора, ребёнок вводит по одному названию и нажимает Enter. Авторы выбираются с учётом числа показов, чтобы пройти весь набор до следующего цикла. История показа сохраняется между запусками. Учитываются регистр, кавычки, пунктуация, «ё/е», дополнительные варианты из редактора и до 1–2 опечаток в достаточно длинных названиях. Короткие и неоднозначные совпадения не угадываются. Программа проверяет только каталог и объясняет это при неизвестном названии.

После хотя бы одного названия можно перейти к вопросам о содержании каждой названной книги. Повтор названия не даёт лишних очков. Подсказки отмечают зависимость ответа и отправляют книгу на повторение. Режим `recall` сохраняется в прежнем формате прогресса и считается направлением «автор → произведения» для освоения.

Кнопка **«1–4 класс»** снимает индивидуальный набор и берёт все 160 произведений, перемешивая их между классами. В библиотеке после этого при желании можно снова ограничить набор.

## Проверки

`node tests.cjs` — каталог, правила, сохранения и режим ввода. `node publisher-tests.cjs` — публикация с имитацией GitHub: обложки, Unicode, сохранение чужих правок, конфликты, ошибочный ключ и потеря ответа после коммита. Настоящий ключ в проверках не используется.

## Магазин · 0.5.0

За самостоятельное сопоставление и верный ответ по содержанию даётся одна монетка. Для каждого произведения доступны два зачёта: `pairs` (включая мемо) и обратное направление (`shelf` или `recall`). Повторы, подсказки и ошибки не приносят монетку в текущей попытке; последующая самостоятельная попытка может получить зачёт. 160 произведений × 2 = 320 монеток.

24 вещи покупаются строго по порядку. Цена списывается из кошелька; купленная вещь остаётся навсегда, её можно надевать и снимать. Сумма цен — ровно 320. Последний образ «Хранитель историй» требует всей библиотеки в обоих направлениях. Кнопка «Заработать монетки» включает подбор ещё не зачтённых заданий. Есть маршрут по всем 1–4 классам.

`rewards.js` хранит цены, зачёты, покупки, миграцию и объединение вкладок. `wardrobe.js` — магазин, примерочную и селфи; `shop.css` — оформление. Новая область `shop` хранится в прежнем ключе `vincent-books-v1`. Баланс рассчитывается из зачётов и покупок, отдельного доверенного числового баланса нет. Прежний учебный прогресс не меняется. Старые вещи и заработанные невыбранные подарки сохраняются; подтверждённые прежние успехи один раз переносятся в монетки. Общий аккаунт и синхронизация между устройствами не добавлялись.

Четыре новых полных образа нарисованы в ImageGen, 24 значка и накладные аксессуары выполнены в SVG. На игрушки и новые костюмы можно нажимать: баттер сжимается, пельмешка прыгает, транспорт двигается. Игрушечный iPhone открывает селфи Винсента с экспортом PNG, без камеры. Есть варианты цвета выбранных предметов. Предусмотрено уменьшение движения в настройках устройства. Происхождение арта и промпты: `ASSETS.md`.

`node rewards-tests.cjs` — проверка экономики, миграции, сохранений, повторов, порядка и полного прохождения.

## Исправление повторяющихся раундов · 0.4.1

Во всех трёх режимах сохраняется история показа по авторам и книгам, отдельно от учебного прогресса. Сначала выбираются авторы с меньшим числом показов, затем учитываются недавний раунд и потребность в повторении. Внутри автора реже встречавшиеся произведения идут первыми. Ошибка или подсказка больше не удерживает одного автора на каждом следующем раунде. История сохраняется при старте раунда, включая незавершённый, и восстанавливается после перезагрузки. При маленьком наборе неизбежны повторы; фильтры класса и индивидуального набора сохраняются.

У каждой книги по-прежнему один вопрос о содержании. Исправление меняет разнообразие книг и авторов, а не добавляет новые вопросы.


## Акварельный арт · 0.5.1

Все 24 карточки магазина используют тёплые акварельные иллюстрации в стиле Винсента. Наряды представлены самим Винсентом в одежде. Примерочная, очки, обувь, шлем, рюкзак, брелоки и игрушки тоже используют этот арт с прозрачностью. Добавлен полный акварельный образ в дождевике. Старые мячик и косточка перерисованы. Монетки, цены, порядок покупок, владение вещами и сохранения остаются в прежнем формате. Источники и промпты: `WATERCOLOR-ART.md`.


## Звуки · 0.5.2

Восемь коротких тихих эффектов с Pixabay: верный ответ, ошибка, монетка, конец раунда, раунд без подсказок, покупка, открытие истории и нажатие на игрушку. Звук включён по умолчанию для новых игроков; кнопка с динамиком в шапке выключает его, выбор сохраняется. Если в последнем вопросе раунда выпала монетка, звучит только финал раунда, чтобы эффекты не накладывались. Источники, обработка и громкость — `ASSETS.md`.

## Исправления · 0.5.2

- Ссылка «К содержимому» больше не сбрасывает текущий раунд.
- Две открытые вкладки не стирают учебный прогресс и историю показа друг друга: при сохранении берётся более свежая запись по каждой книге.
- Описание книги на поле «Найди пару» спрятано в подсказку «Вспомнить историю», а в «Собери полку» вместо описаний показан жанр. Раньше ответ на вопрос о содержании читался прямо с поля и засчитывался как самостоятельный.
- Если в наборе один-два автора, в «Найди пару» добавляются авторы-отвлекатели: пара больше не складывается сама.
- После каждого действия фокус клавиатуры остаётся на нужной кнопке, сообщения об ошибках зачитываются экранным диктором. Неверная пара подсвечивается терракотовым.
- «Вспомни названия»: верное название, уже зачтённое ранее, больше не считается подсказкой для всего раунда.
- Общие ссылки работают на iPad с iPadOS 15–16; ссылка с полным набором передаёт `books=all`; параметры убираются из адреса после применения.
- Редактор: очистка поля ссылки не удаляет опубликованную обложку; черновик удалённой карточки не блокирует публикацию.
- Магазин: фокус возвращается к купленной вещи после закрытия окна; селфи освобождает память.

## Оформление «Ночная библиотека» · 0.6.0

Игра переоформлена в тему вечерней библиотеки: тёмно-синяя комната, тёплый свет лампы, полка с книгами и золотые монетки. Всё, что ребёнок читает (вопрос, текст истории, пояснения, окна), подаётся светлой бумажной страницей, чтобы глаза не уставали.

- Шрифты: Yeseva One для заголовков, Nunito для интерфейса, Literata для чтения.
- Текст не мельче 14 px, основной 17–18 px, кнопки от 52–60 px с «нажатием».
- На телефоне и планшете шапка в две строки: монетки — золотая кнопка магазина рядом со звуком.
- Тема лежит в `night.css` (игра) и `night-shop.css` (магазин, примерочная, окна покупки и селфи) поверх прежних стилей. Редактор `admin.html` их не подключает и остаётся светлым. Откат темы — убрать две строки `<link>` в `index.html`.
- Селфи Винсента сохраняется в той же ночной палитре.

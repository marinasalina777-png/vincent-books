# Книжная мастерская Винсента

Обучающая игра о литературе для 1–4 классов. Версия 0.4: 160 карточек, все 102 пронумерованные позиции присланного списка, два направления сопоставления, мемо, самостоятельный ввод названий, вопросы, чтение и сохранение прогресса. Подарки за каждые 10 ответов, гардероб и ссылки на аудиокниги. Есть редактор обложек и описаний. Работает без сборки.

## Запуск

Игра и редактор запускаются по HTTP. Для локальной проверки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4173. Опубликованные правки загружаются из `overrides.json`. Внешнее подключение используется для шрифтов Google Fonts, картинок по внешним ссылкам и перехода к источникам; при недоступности шрифтов используются системные. Все игровые данные и иллюстрация находятся в репозитории.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `vincent-books`.
2. Загрузите в корень содержимое этой папки, включая `assets` и `.nojekyll`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Дождитесь успешной публикации и возьмите адрес со страницы Pages.

Относительные пути позволяют разместить игру в `https://<аккаунт>.github.io/<репозиторий>/`.

## Файлы

- `SPEC.md` — согласованное ТЗ, границы версии и дальнейшие шаги.
- `CATALOGUE.md` — построчная сверка всех 102 позиций фотографий, конкретные выбранные рассказы и главы.
- `data.js` — каталог; добавление произведения через `add`, вопросы можно расширять.
- `engine.js` — независимые правила раундов и учёта прогресса.
- `app.js` — экраны и взаимодействие.
- `styles.css` — оформление и анимации.
- `assets/vincent.png` — прозрачная иллюстрация Винсента, сгенерированная встроенным инструментом по пользовательскому референсу.
- `ASSETS.md` — описание происхождения арта и финальный промпт.
- `tests.cjs` — проверки игровых правил. Запуск: `node tests.cjs`.

## Контент и ограничения

Представлены все 95 отечественных и 7 зарубежных пронумерованных позиций фотографий. Они раскрыты в 160 карточек: в строке может быть несколько названий. Открытые циклы, былины, народные жанры и главы «по выбору» представлены конкретными текстами с примечаниями. Все явно перечисленные названия включены. Это покрытие списка, а не утверждение о включении каждого рассказа каждого упомянутого цикла. Полная сверка — `CATALOGUE.md`.

Внутри доступны 65 текстов и обозначенных отрывков общественного достояния. Другие карточки содержат написанные для игры пересказы и ссылки на русские тексты. Современные тексты и переводы без разрешения не копировались. Классы целой строки таблицы перенесены на все её произведения. У совпадающих названий разных авторов на игровом поле показан сюжетный ориентир.

Для каждой книги пока один вопрос. Следующий проход добавит варианты, чтобы ребёнок не запоминал положение или формулировку ответа. Порядок ответов уже перемешивается.

Прогресс хранится в браузере под ключом `vincent-books-v1`. Экспорт доступен в «Об игре». Импорт и синхронизация пока не реализованы. Не добавляйте в публичный репозиторий детские персональные данные, ключи или выгруженные сохранения.


## Редактор карточек

Откройте [admin.html](admin.html). Он доступен также через «Для родителей · редактор» внизу игры.

1. Найдите произведение по названию или автору.
2. Загрузите JPG/PNG/WebP (до 20 МБ; браузер уменьшает до 850 px и JPEG), либо вставьте HTTPS-ссылку на изображение.
3. Измените описание и добавьте HTTPS-ссылку на страницу аудиокниги. Ссылки открываются отдельно; автоматического чтения и воспроизведения нет.
4. Нажмите «Сохранить черновик», затем «Посмотреть в игре». Только URL с `?preview=1` применяет черновики. Обычные игроки видят опубликованную версию.
5. «Опубликовать для всех» отправляет правки в этот же репозиторий GitHub. Дождитесь обновления GitHub Pages.

Для прямой публикации нужен GitHub fine-grained personal access token: только репозиторий `vincent-books`, разрешение **Contents → Read and write**. Пошаговая инструкция есть в окне публикации. Ключ вводится в скрытое поле, отправляется только на `https://api.github.com`, не сохраняется в хранилище, экспорте или репозитории. После закрытия окна или завершения публикации поле очищается. Редактор доступен публично, общую версию может менять лишь владелец подходящего ключа.

Черновики с обложками сохраняются в IndexedDB отдельно от детского прогресса. Кнопки «Скачать копию» / «Восстановить из копии» переносят правки между устройствами. Перед переходом к другой карточке редактор сохраняет заполненную карточку; при закрытии окна с несохранёнными полями браузер предупреждает. Перед публикацией сохраняются все текущие поля.

Обложки публикуются отдельными файлами с хешем в `assets/covers/`; `overrides.json` содержит только пути, описания, ссылки и допустимые варианты названий. Изменения других карточек сохраняются, конфликт правок одной карточки останавливает публикацию. SHA файла защищает от гонки при последней записи. При потере соединения после отправки результат сверяется повторным чтением. Неиспользованные изображения после неудачной публикации не влияют на каталог.

Встроенное синтетическое озвучивание удалено. `narration.js` оставлен пустой совместимой заглушкой, не подключается к игре. Звуки успеха — отдельный необязательный эффект.

## Самостоятельный ввод

«Вспомни названия»: случайно выбирается автор из текущего набора, ребёнок вводит по одному названию и нажимает Enter. При наличии других авторов следующий не повторяется. Учитываются регистр, кавычки, пунктуация, «ё/е», дополнительные варианты из редактора и до 1–2 опечаток в достаточно длинных названиях. Короткие и неоднозначные совпадения не угадываются. Программа проверяет только каталог и объясняет это при неизвестном названии.

После хотя бы одного названия можно перейти к вопросам о содержании каждой названной книги. Повтор названия не даёт лишних очков. Подсказки отмечают зависимость ответа и отправляют книгу на повторение. Режим `recall` сохраняется в прежнем формате прогресса и считается направлением «автор → произведения» для освоения.

Кнопка **«1–4 класс»** снимает индивидуальный набор и берёт все 160 произведений, перемешивая их между классами. В библиотеке после этого при желании можно снова ограничить набор.

## Проверки

`node tests.cjs` — каталог, правила, сохранения и режим ввода. `node publisher-tests.cjs` — публикация с имитацией GitHub: обложки, Unicode, сохранение чужих правок, конфликты, ошибочный ключ и потеря ответа после коммита. Настоящий ключ в проверках не используется.

## Подарки
Новая область `wardrobe` в прежнем сохранении хранит число завершённых ответов по содержанию, полученные вещи, выбранный образ и игрушку. Существующий учебный прогресс сохраняется. Каждый десятый ответ даёт один подарок на выбор; платёжных функций нет.
